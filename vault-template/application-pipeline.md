# Application Pipeline

*Living tracker. Each row is a note in `wiki/applications/`, rendered here as table views of `applications.base`.*

Stage values (the **Stage** column): `found` → `applied` → `ongoing` → `accepted` / `rejected`, plus `skipped` for roles you pass on.

## Live tracker

*Clip a posting (optional, if you use the Obsidian Web Clipper) or just say "find jobs" to run the scout. Each job becomes a note in `applications/`, and that note is a row here. Change a stage by clicking the Stage cell and picking from the list, or say "applied to X". Other views of the same data: All · Outcomes · Cards (open `applications.base`).*

### Inbox — new finds from the job scout
*Say **"find jobs"** or wait for a scheduled run if you set one up. Set the Stage to `applied` once you apply, or `skipped` if it's not for you. You can also tell Claude "applied to X" / "skip X". Skipped roles never come back.*
