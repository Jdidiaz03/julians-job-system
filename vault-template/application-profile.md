## Logins
- Existing accounts (company already applied to): job-apply uses the password saved in the macOS **login Keychain** for that site (`"login": true`, never printed). To save a password for a site you've already signed up to elsewhere: `security add-internet-password -U -s <site domain> -a <your email> -w` in Terminal (it prompts for the password, so it never appears in chat). Or just log in once in the browser window job-apply uses: it keeps you logged in.
